# Contributing

Issues and pull requests are welcome. Keep changes focused, avoid committing
credentials or runtime databases, and test the bridge API and the native
Home Assistant entities.

For a release, update the version in `home_assistant_app/config.yaml` and
`home_assistant_app/CHANGELOG.md`, then create a matching `app-vX.Y.Z` tag.
